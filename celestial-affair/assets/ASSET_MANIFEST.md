# Artwork slots (v5)

All artwork is selected in `START_HERE.bat`. The wizard copies selected images to `assets/user/` and writes `art-manifest.js`.

| Slot | Recommended artwork | File expectations |
| --- | --- | --- |
| Invitation | Finished 5 x 7 art; text baked in | 1500 x 2100 PNG or larger |
| Background | Dark navy sky, optional texture | Wide PNG/JPG/WebP, fills screen |
| Constellations | Several star-line masks | Transparent PNG, WebP, or SVG |
| Clouds | **At least 3 variants** for left, right, foreground | Transparent PNG or WebP |
| Planets | Several drawn planets | Transparent PNG or WebP |
| Ornaments | Gold stars, telescope, decorative motifs | Transparent PNG, WebP, SVG |

No generated images are distributed with v5. Until you select drawings, the page shows a plain dark blue background and a labeled 5 x 7 artwork slot. All individual images can be replaced independently. Additional cloud variants cycle left/right/front and overlap. Scroll controls their departure and the planet appearance.

Because your entire invite is one image, there is no title, date or location repeated outside it. Guest personalization remains in the RSVP section below.
