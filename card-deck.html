03 / LOOKUP  ·  Enrich cards, fetch logos, merge duplicates▾

Area code → city, state and time zone. Email domain → company, country and sector. Address → city, state, zip. Costs nothing and works with no internet.

Tries Clearbit, then Google's favicon service. The logo is stored in the card, so it keeps working offline afterwards. Both services see the domain you look up.

Infers industry and sector tags from what's on the card. Ollama refuses browser requests by default — start it with OLLAMA_ORIGINS=* or this can't reach it. Everything a model proposes lands in a suggestions row you approve; nothing is written to a card behind your back.

A page can't be fetched directly from a local file — the browser blocks it. A text-extraction endpoint works around that, at the cost of showing a third party which sites you look up. Off unless you fill this in. Anything it returns is treated as text to summarise, never as instructions.

04 / DATA & SYNC  ·  Google Sheet, backup, wipe▾

Needs the companion Apps Script deployed as a web app. Text, tags and logo URLs sync; card photos stay on this device, since a sheet cell holds 50,000 characters and one photo is several times that. Deleting a card writes a tombstone row so the deletion carries across devices instead of coming back on the next pull.
